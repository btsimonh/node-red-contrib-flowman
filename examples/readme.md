# Examples for node-red-contrib-flowman

## simpleadddelete.json

Import from the Node-RED menu: Import > Examples > node-red-contrib-flowman > simpleadddelete.
(Or copy the content of simpleadddelete.json and import from clipboard.)

This flow can add a simple flow called 'myFlow', delete the last added 'myFlow', and delete all flows with label 'myflow'.
